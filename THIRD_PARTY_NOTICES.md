# Third-party data

## free-exercise-db

- Repository: https://github.com/yuhonas/free-exercise-db
- License: [The Unlicense](https://unlicense.org/) (public domain)
- Bundled file: `public/data/exercises.json` (combined export)
- Exercise images: loaded at runtime from `https://raw.githubusercontent.com/yuhonas/free-exercise-db/main/exercises/`

To refresh the JSON from upstream:

```bash
npm run sync-exercises
```
